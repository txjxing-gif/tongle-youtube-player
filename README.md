# 同乐YOUTUBE本地播放器——使用说明

> 本文写给第一次拿到播放器的用户。除打赏二维码外，全文只用文字说明，没有图片；读屏用户可以直接听。

## 一、这是什么，给谁用的

同乐YOUTUBE本地播放器是一个 Windows 桌面播放器，用来在电脑上看 YouTube 视频、听 YouTube 音频。

它是先给读屏用户做的，再兼顾明眼人：

- 全是标准 Windows 控件加真实文字，读屏软件能直接读。
- 任何操作都有键盘和鼠标两条路，不会只有鼠标能点、也不会只有快捷键能办。
- 状态变了会说话：播上了、换档位了、出错了，都会播报一句。
- 默认只播声音、不播画面，省流量；想看画面随时可以开。

播放没有广告。播放走本机中继边播边取，不把整段视频下载到硬盘，只看个开头就关掉，也只花了开头那点流量。

不登录也能搜、能播。登录后才能用订阅、评论、点赞这些要账号的功能。登录走谷歌官方登录，你在自己的浏览器里输账号密码、点同意，密码和令牌不会交给别人。

## 二、下载与安装

下载地址：https://github.com/txjxing-gif/tongle-youtube-player/releases/tag/v1.3（链接很长，请直接在电脑上点开本文里的链接，或请明眼家人帮忙打开，不要凭听写输入）

公开版放在 GitHub 发布区当下载附件（仓库里只放本使用说明和打赏二维码，不放源码）。

下载到的就是一个 EXE 文件，自带 .NET 运行库，不用另外装 .NET，也没有安装向导：下载下来，放在一个固定文件夹里，双击就能打开。以后有新版不用重新下载，在播放器里点帮助菜单“检查更新”走在线更新就行。

注意放的位置：不要直接放在桌面、下载、文档、图片、音乐、视频、OneDrive、Temp、公共文件夹这些文件夹里，也不要放在 C 盘、D 盘等盘的根目录，更不要放在系统文件夹（如 Windows、Program Files、AppData）里，也不要放在播放器自己的数据文件夹（%APPDATA%\TongleYoutube）里。更新时播放器要整体更换自己所在的文件夹，放在这些地方会动到其他文件，播放器会拒绝更新。最稳妥是新建一个专用文件夹，例如 D 盘或 C 盘下的同乐播放器文件夹，把 EXE 移进去再打开——是移，不是拷：移过去后删掉旧位置那个，不要再从旧位置打开，否则旧位置那个还是旧版，下次更新还会失败。设置和登录信息存在别处（不在 EXE 旁边），移动 EXE 不受影响；如果你自己在 EXE 旁边放了 ffmpeg.exe，记得连它一起移过去。

第一次打开时，播放器可能会请你确认一次网络权限，点允许就行。

## 三、第一次使用：填密钥、登录

公开版里不带任何密钥。登录、翻译、云端语音这三件事，各用各的密钥，都由你自己填，都只加密存在你自己的电脑上，绝不发到别处。

填密钥的地方都在设置窗里：按 F4 打开设置，填完按 Tab 到保存按钮再确认。输入框里按回车不会保存。

### 1. 实时翻译密钥（翻译要用）

字幕翻译和实时翻译（同声翻译）走谷歌 Gemini 在线翻译，需要一个 Gemini 密钥。没有密钥时开翻译开关，播放器会播报原因、引导你去设置。

去 Google AI Studio 免费领一个（免费档不用绑卡，额度按谷歌的规定来）：

1. 打开 aistudio.google.com，用谷歌账号登录。
2. 点 Get API key（拿 API 密钥）。
3. 点 Create API key（创建密钥），选一个谷歌云项目（没有就新建一个）。
4. 复制生成的密钥。
5. 回到播放器，按 F4 打开设置，在“实时翻译密钥”那一栏粘贴进去，保存。

> 按钮上的实际文字以谷歌页面的为准，页面改版时可能换名字。密钥就是一串密码，不要发给别人，也不要贴到公开的地方。

### 2. 登录凭证（登录 YouTube 要用）

登录要走你自己的谷歌云 OAuth 凭证。播放器设置里有两栏：“登录凭证编号”和“登录凭证密钥”，两项必须都填，只填一项不算数。

在谷歌云控制台建一个桌面应用凭证，大致步骤如下（一次性操作，约十分钟）：

1. 打开 console.cloud.google.com，建一个谷歌云项目（没有就新建一个）。
2. 在“API 与服务 → 库”里搜“YouTube Data API v3”，点启用。
3. 在“API 与服务 → OAuth 同意屏幕”里选用户类型“外部”，填应用名和你的邮箱，保存。
4. 在同一页的“测试用户”里点添加用户，把你要登录的那个谷歌账号加进去。应用在测试状态时，只有加进来的账号能登录。
5. 在“API 与服务 → 凭据”里点“创建凭据 → OAuth 客户端 ID”，应用类型选“桌面应用”，起名后点创建。
6. 把生成的“客户端 ID”复制到播放器的“登录凭证编号”栏，把“客户端密钥”复制到“登录凭证密钥”栏，保存。

> 按钮上的实际文字以谷歌云控制台的为准。登录时播放器会请求三项权限：只读你的订阅和账号信息、发评论、改订阅。同意页上会列出来，你点同意就行。
>
> 注意：你的应用在谷歌那边是“测试”状态时，登录令牌大约 7 天过期，过期后要重新登录一次。这是谷歌的规定，不是播放器的问题。长期免重新登录要走谷歌的应用验证，那是另外的流程，本说明不展开。

### 3. 登录步骤

1. 按 Ctrl+L，或者打开账号菜单点“登录”。
2. 播放器打开系统浏览器，到谷歌登录页。你自己输账号密码、点同意。
3. 同意后浏览器会显示一个中文成功页，可以关掉它，回到播放器。
4. 播放器播报“登录成功，账号是某某”，状态行也会显示你的账号名。

账号菜单是下拉菜单：顶级恒为“账号”，下面有“登录/取消登录/登出”（按登录状态变，Ctrl+L 字样一直显示）、“登录凭证设置…”（打开设置窗并定位到“账号与密钥”页签）、“当前账号：xxx”（点它播报当前账号与登录态，不改状态；未登录显示“未登录”；长账号在菜单里只显示前 40 字（含“当前账号：”前缀））。Ctrl+L 与菜单首项同一动作：没登录时触发登录，登录中按了取消登录，已登录按了弹确认框、确认后登出。

登录信息只加密存在你自己的电脑上。想退出就打开账号菜单点“登出”，内存和磁盘里的令牌都会清干净。如果想彻底撤销授权，要去谷歌账号的第三方应用里自己移除，播放器不代劳。

### 4. 云端语音密钥（可选）

朗读语音有三路，见第五节第 4 条。只有选“云端”嗓音时才需要 Azure 密钥：去微软 Azure 开一个语音资源，拿到密钥和区域，填到设置的“Azure 密钥”和“区域”两栏。区域默认是 eastasia（东亚），填你自己资源的区域。密钥存在本机加密文件里。

不用云端嗓音就不用填，本地语音和 Edge 在线语音都不需要密钥。

## 四、日常使用

### 1. 搜索与播放

1. 按 F 聚焦到搜索框，输入要找的内容，按回车搜索。
2. 搜索结果每页 30 条，按上传日期从新到旧排。
3. 在结果列表里用方向键选一条，按回车就播。选中上一页或下一页那一项时按回车是换页。

浏览菜单里“搜索”是执行搜索，空着没输关键词就点它，只会播报一句“请先输入搜索关键词。”，不会搜，焦点还放回搜索框，可以直接输入；“定位到搜索框（F）”只是把焦点移到搜索框，不搜。

播放时默认只播声音。想看画面，到播放菜单“质量”里选 1080p、720p、480p 或 360p；想只听声音就选“仅音频”。起播时只有实际档位和你选的不一样时才播报一句，其他时候静默。

播放中位置连续 15 秒不动，会播报一句“播放停滞。”，每个停滞段只报一次。

### 2. 翻页、分类、订阅、频道

- 下一页：按 R 键，或者到列表末尾选“下一页”那一项按回车。上一页没有快捷键，走浏览菜单“上一页”，或者列表末尾的“上一页”项。
- 刷新列表：按 F5，从第一页重拉。
- 分类浏览：按 F7，展开分类子菜单（顶部是“切换分类地区…（F9）”，下面是 10 个分类：订阅动态、热门、音乐、游戏、新闻、体育、娱乐、教育、科技、直播），方向键选、回车打开。分类浏览要登录，每次打开强制刷新。订阅动态是已订阅频道的最新视频。分类地区默认台湾，在设置“分类地区”里改（全部 109 个地区），也可以按 F9 快速切换，改了之后正在看的分类当场按新地区重刷。
- 我的订阅：按 F8，打开订阅对话框。频道列表里按回车或双击打开频道；点右键有频道菜单（打开频道、频道播放列表、频道简介、频道内搜索、网页打开、取消订阅），对话框底部也有一排同样的按钮，不依赖右键也能操作。点“频道播放列表/频道简介/频道内搜索”后订阅框先关、主窗再开子对话框，Esc 从子框回主窗；重按 F8 回订阅列表。
- 频道播放列表：每个播放列表对话框每页 30 个，选一个打开进主列表。
- 返回上一级：按退格键。从频道或播放列表钻进去后，退格回到上一级，不重新拉取；多级钻取逐级退回。没有上一级时播报“没有上一级”。焦点在输入框里时退格仍是删除文字。
- 播链接：按 F6（浏览菜单“播放 URL…”），粘贴视频链接后确认就播。
- 订阅频道：对列表里某一个视频点右键选“订阅/取消订阅”，已经订阅的点它走取消订阅确认框；操作栏“更多操作”里也是同一菜单。

订阅和网页版是同一份数据，双向同步。通知设置（小铃铛）没有官方接口，做不了，菜单里没有这一项。

### 3. 继续观看

浏览菜单“继续观看…”打开继续观看对话框：上面有三张卡（我的订阅有几个频道、播客有几个订阅、继续观看有几部没看完），下面是继续观看列表（最近没看完的视频，最多 10 条），回车就从上次停的地方续播。

播到 90% 就算已看完。列表里“观看进度”那一列会写“已看完”或“还剩几分钟”。手动标记走右键菜单或操作栏的“标记为已看”（已经看过的视频，那里显示的是“取消已看标记”）。

### 4. 播客

浏览菜单“播客…”打开播客对话框。在订阅源地址框里输入 RSS 或 Atom 地址，按回车添加；也可以点“导入 OPML”批量导入。打开订阅进单集视图，回车就播；退格键回订阅列表。订阅顺序可以在订阅视图里用“上移、下移、移到顶部、移到底部”调，或者用鼠标拖。

### 5. 评论

- 看正在播的视频的评论：按 C（浏览菜单的评论项已删，只剩 C 键），打开评论对话框，自动加载评论；对话框里可以加载更多、朗读评论、发表评论。置顶评论作者前显示“置顶 ”，回复评论内容前显示“回复：”，朗读时同样加上。
- 看列表里某一个视频的评论：对它点右键选“查看评论”，只读，只能看不能发表，不登录也能点。
- 对列表里某一个视频发表评论：点右键选“发表评论”，要登录；删自己在这个视频上发过的评论，点右键选“删除我的评论”，也要登录。

## 五、字幕、翻译与语音

### 1. 字幕

- S 键：朗读字幕开或关（开关，整路朗读）。
- T 键：朗读这一句字幕（单次，只读当前这一句）。
- N 键、P 键：下一条字幕、上一条字幕，并跳到那条的起点。
- 字幕菜单“字幕语言”可以换轨道；没有字幕轨道时只显示一行不可用的“（暂无字幕轨道）”。
- 字幕菜单“字幕文本稿”打开全部字幕行的列表，可以搜索、跳转。

很多视频本身就没有字幕，特别是音乐类视频。这是正常的。

### 2. 字幕翻译

按 Y 键，或者字幕与翻译菜单勾选“翻译字幕”，就把非中文的字幕文字翻成中文显示和朗读。走 Gemini 在线翻译，需要实时翻译密钥（第三节第 1 条）。翻译失败的那行保留原文，不打断播放。

### 3. 实时翻译（同声翻译）

按 U 键或 F3，或者字幕与翻译菜单勾选“实时翻译”，播放时自动识别视频里的说话声音，边播边翻成中文语音播出来（同声传译），同时显示译文。原声会压到六成音量，翻译停了就恢复。快进快退后会自动跟到新位置。

要点：

- 需要实时翻译密钥，没密钥时开开关只播报原因，不会弹框。
- 开关打开 45 秒内是预热期，看门狗不播报；预热过后识别停滞 30 秒才播报一句“实时翻译正在识别中，暂无新译句。”
- 换视频时自动在新视频上重启。
- 实时翻译不限英语，模型自动识别源语言。

### 4. 朗读语音设置

按 F4 打开设置，“朗读语音”那一栏有三路，选中哪个就用哪路：

- 本地：用你电脑本机装的语音，不用联网。
- 在线：Edge 在线语音，免密钥，有 6 个中文嗓：晓晓、晓伊、云健、云希、云夏、云扬。
- 云端：Azure 云端语音，需要你自己的 Azure 密钥和区域。嗓音下拉里显示“中文名（原名）”，有官方中文名的显示中文名，没有的显示原名。

语速、语调只对在线语音（Edge 和 Azure）生效，本机语音不支持语调。播报音量（0到100，每次加减 5，默认 100）对本机、在线、云端三路都生效，只调播报声，不影响视频音量；对话框里改值立即生效，取消则恢复原值。设置里有“试听选中嗓音”和“重新检测嗓音”两个按钮。

### 5. 视频摘要

对正在播放的视频，按 G 键（浏览菜单的摘要项已删，只剩 G 键），会根据字幕提炼要点，打开摘要对话框。

列表里也可以对某一个视频点右键选“视频摘要”，只取你点的那一个视频的字幕现场生成，不会去批量取整个列表的字幕。

摘要有两种方式，在设置“摘要方式”里选：

- 本地抽取（无需密钥）：从字幕里抽关键句，不要密钥。
- 在线模型（兼容接口）：要用你自己的接口地址、模型名和模型密钥。

没有字幕的视频做不了摘要，只播报一句“没有字幕，无法生成摘要。”，不弹对话框。这是设计好的，不是坏了。

## 六、播放设置

都在设置窗（F4）里，分 6 个页签（语音、播放、账号与密钥、外观、下载与网络、快捷键，Ctrl+Tab 或方向键切换），常用的有这些：

- 质量与倍速：倍速按 F2 循环（0.5、0.75、1、1.25、1.5、2.0）；质量在播放菜单里切。每个频道会记住你上次用的倍速、质量、仅音频和音量，下次播这个频道的视频自动沿用，只有和当前设置不一样的项才播报一句。
- 缓冲预设：省流量 2000 毫秒、默认 5000 毫秒、流畅优先 10000 毫秒三档加自定义，保存后下次启动生效。只听声音时固定用 1000 毫秒。
- 均衡器：关闭、语音清晰、减少低音三档，默认关闭；只改变播出来的声音，不影响翻译和字幕朗读。
- 分类地区：分类浏览（热门、音乐、游戏这些榜单）按哪个地区取，默认台湾；设置里“分类地区”可以改，全部 109 个地区；也可以按 F9 快速切换，改了之后正在看的分类当场按新地区重刷。
- 众包片段跳过（默认开）：自动跳过视频里众包标记的片段（比如赞助商口播、片头片尾），每跳一次播报一句。默认跳过赞助商片段、片头、片尾、自我推广四类，其余类别可以在设置里勾选。直播永不跳段。
- 众包简洁标题（默认开）：列表里显示众包提供的简洁标题。
- 列表显示：列表和网格两种视图；主题、强调色、界面缩放、列表密度也在设置里。
- 直播提醒（默认关，要登录）：从订阅里最多选 20 个频道，每 15 分钟查一次，开播播报一句，每场只提醒一次。自动下载直播是另外一个独立开关，默认关。
- 选中预取（默认开）：在列表里选中某视频停留满 0.8 秒，后台悄悄取好播放信息，回车更快；失败不播报不弹框。
- 网络代理：留空自动读系统代理。保存后登录、搜索、下载、语音、摘要、更新立即用新代理；实时翻译下次开始时用新代理；本地中继与播放要重启播放器才生效。

播放行二的“播放选项”按钮打开一个对话框，可以改倍速、质量和字幕轨道。剧场模式和全窗口模式只改布局、不碰播放，位置保留；按 Esc 可以按顺序退出全屏和模式。

## 七、快捷键全表

快捷键可以自己改：设置窗（F4）第 6 页签“快捷键”，点动作的当前按键、再按新按键即可改，Esc 取消；改完按保存立即生效，不用重启；列表上方的“恢复默认”清空全部自定义（按保存后生效）。改键后菜单和帮助里的键位说明同步变。

裸字母键在输入框、下拉框里不触发，功能键（F1–F9）和带 Ctrl/Alt 的组合在输入框里也触发；改键后按新键的形态走。菜单栏获得焦点时（按 Alt 后），字母键属于菜单导航，快捷键不触发。每个快捷键都有对应的菜单项，鼠标键盘双通道，绝不只有快捷键一条路。例外：I 键详情查询是纯快捷键（无菜单项）；Esc 只保留按键功能；评论（C）无菜单项（浏览菜单的评论项已删，只剩 C 键）；退格返回无菜单项；系统级全局键 Shift+上/下（音量加/减）与 Shift+上翻页（托盘循环开关）没有菜单项。

### 搜索、列表与登录

- 回车（搜索框内）：搜索，每页 30 条。
- 回车（结果列表内）：播放选中视频；选中上一页或下一页项时换页。
- R：下一页。
- 退格键：返回上一级；没有上一级时播报“没有上一级”。
- F 或 Ctrl+F：定位到搜索框（F）。
- Ctrl+L：登录/登出；已登录时弹确认框、确认后登出；登录中取消登录。
- F5：刷新当前列表。
- F6：播放链接，粘贴地址后确认就播。
- F7：分类浏览。
- F8：我的订阅。
- F9：切换分类地区，打开地区选择对话框，方向键选地区、回车应用，Esc 取消；与设置里的“分类地区”同一功能。
- Alt+Enter：全屏或取消全屏，主界面任何焦点都生效。
- Menu 键或 Shift+F10：在列表焦点项处打开右键菜单（打开方式尚未真机验证，右键点击本身可用）。

### 播放控制

播放菜单分四组：播放控制（播放、快退、快进）、静音切换、倍速、质量、章节、众包片段、视图模式（全屏、剧场模式、全窗口模式）；其中“章节”、“众包片段”是打开对话框的入口。

- 空格：播放或暂停，菜单上的文字跟着变：没播时是“播放”，播着是“暂停”，加载中是“取消”，按了停掉本次加载。焦点在播放焦点、视频画面或空白处时生效；结果列表内空格没动作；焦点在按钮上时空格照常点按钮。缓冲中按空格停掉本次加载。
- 播放焦点内上箭头、下箭头：音量加、减 10。
- 播放焦点内左箭头、右箭头：快退 30 秒、快进 30 秒。
- 拖动条上方向键、PageUp、PageDown、Home、End：不寻址，只在第一次获焦时播报一句引导；拖动条请用鼠标拖。
- 音量滑块上方向键：调音量，改值立即播报新音量。
- F2：倍速循环，每按升一档（0.5、0.75、1、1.25、1.5、2.0，再按回绕到 0.5）。
- I：播报当前状态、位置、播放地址、播放来源与最近一次错误。
- Esc：按顺序只做第一件适用的事：全屏时先退出全屏；剧场或全窗口模式时退回普通模式并播报；既不是全屏也不是模式时，停止一切语音播报，并取消正在进行的下载、登录与搜索。对话框里的 Esc 只关闭当前对话框。
- Shift+上箭头、Shift+下箭头：音量加、减 10（系统级全局键，其他窗口在前台、播放器最小化后都生效）。
- Shift+左箭头、Shift+右箭头：快退、快进 30 秒（系统级全局键）。
- Shift+Home：播放或暂停（系统级全局键）。

注意：播放器运行时，Shift 加方向键和 Shift+Home 在全部程序里都被播放器占用，其他程序里的选字、行首选中暂时不可用，退出播放器后恢复。

### 字幕、翻译、评论、下载、摘要

- S：字幕朗读开或关。
- T：朗读这一句字幕。
- N、P：下一条、上一条字幕，并跳到那条起点。
- Y：字幕翻译开或关。
- U 或 F3：实时翻译开或关。
- C：打开评论对话框（看正在播的视频的评论；置顶评论作者前显示“置顶 ”，回复评论内容前显示“回复：”，朗读时同样加上）。
- D：打开下载对话框。
- G：打开摘要对话框并生成摘要。

### 通用

- F1：打开帮助窗（帮助菜单“快捷键与操作说明”）；设置窗里按裸 F1 也可以打开。
- F4：打开设置窗。
- Tab、Shift+Tab：在控件间移动。顺序是：导航栏（我的订阅、分类浏览、播客、设置、展开/收起）、搜索框、结果列表、操作栏（播放、下载、转到频道、复制链接、标记为已看、更多操作；有选中时 6 停，无选中时 6 个按钮禁用、Tab 跳过）、播放焦点、剧场模式、全窗口模式、播放选项、当前字幕、实时翻译。搜索按钮、回到顶部、回到底部、拖动条、音量减、音量加、音量滑块、静音、收起列表只留鼠标点，不进 Tab 序；菜单栏走 Alt，视频画面不在 Tab 序内，状态栏不进 Tab 序。收起列表按钮读屏可能报“收起结果列表”。
- Alt：打开菜单栏；Alt 加菜单助记符字母直接打开对应菜单（播放 P、字幕与翻译 Z、浏览 B、账号 A、帮助 H、退出 X；设置没有助记符，Alt+S 是定位搜索框）。

### 对话框里的按键

- 章节、众包片段对话框：方向键浏览，回车或双击跳到起点，关闭后焦点回结果列表。
- 字幕文本稿对话框：搜索框内回车查找下一处；列表内回车跳到该行起点，对话框保持打开，可以连续跳转。
- 播客对话框：列表内回车或双击打开订阅或播放单集；订阅源地址框内回车添加订阅源；单集视图内退格键回订阅列表。
- 播放选项对话框：倍速滑杆上方向键只改预览，回车或鼠标松开才应用并关闭；字幕列表内回车应用选中的轨道。
- 继续观看对话框：列表内回车或双击从保存位置续播。
- 我的订阅对话框：频道列表内回车或双击打开频道。
- 设置窗：输入框内回车不保存，要 Tab 到保存按钮再确认；Esc 取消；裸 F1 打开帮助。

### 没有快捷键的功能（走菜单或按钮）

章节、众包片段、字幕文本稿、剧场模式、全窗口模式、网格视图、播客、继续观看、收起列表（收起后显示为“展开列表”）、复制视频链接、标记为已看（已看过的视频显示为“取消已看标记”）、查看评论（右键菜单）、搜索按钮（搜索行按钮）、播放选项、回到顶部、回到底部、导航栏展开与频道头像、检查更新。这些都有菜单或按钮入口，绝不只有鼠标一条路。

## 八、常见问题

### 视频没有字幕，摘要也不出对话框

正常。很多视频本身就没有字幕，特别是音乐类视频。点“视频摘要”后只会播报一句“没有字幕，无法生成摘要。”，不弹对话框。换一个有字幕的视频再试。

### 字幕一直加载失败

可能是字幕服务限流。播放器遇到限流会冷却 10 分钟，期间不再反复去取，只播报一次。等一会儿再试，或者换个视频。如果一直失败，看看是不是网络或代理的问题。

### 下载时提示要登录验证（机器人检查）

播放器会等 60 秒自动重试一次，并播报“遇到验证，正在重试。”。重试还不行就按失败处理，播报短原因。下载本身不依赖登录，失败一般是对方的验证，与登录状态无关。

### 登录后关掉重开，登录就没了

这个问题已经修了：以前令牌存盘写的是空内容，重开读出来是空的，所以每次都要重新登录。现在令牌能正确存盘，登录一次就会留住。如果新版里还遇到，请把日志文件发给我们：按 Win+R，输入 %APPDATA%\TongleYoutube 后按回车，打开里面的 debug.log 发过来。日志里只记结果，不记令牌值。

### 点登录提示“登录未配置”

说明“登录凭证编号”和“登录凭证密钥”没填或只填了一项。按第三节第 2 条，在设置里两项都填好再登录。

### 开翻译提示没有密钥

说明“实时翻译密钥”没填。按第三节第 1 条领一个免费密钥填进去。字幕翻译和实时翻译共用这一个密钥。

### 更新失败

帮助菜单“检查更新”失败时，播放器会保留一个对话框说明原因。常见原因是更新信息缺少签名或签名验证失败，这时不要强行安装，等新版。

如果你听到的是“主程序不在安装目录内，无法更新。”，说明你用的 1.0 或 1.1 版更新器本身有缺陷，应用内更新修不好它：先关闭播放器，到下载地址（第二节）手动下载 1.3 的新包，把新 EXE 移进一个专用文件夹（例如 D 盘或 C 盘下的同乐播放器文件夹），删掉旧位置那个，再从新位置打开。设置和登录不受影响。1.3 的更新器改成认 EXE 所在的文件夹，修的就是这个缺陷。

另一个常见原因是主程序放在了桌面、下载、OneDrive、Temp、公共文件夹等系统文件夹里或磁盘根目录：更新要整体更换主程序所在的文件夹，这些地方不能更新，播放器会直接说明原因。这时先关闭播放器，新建一个专用文件夹（例如 D 盘或 C 盘下的同乐播放器文件夹），把 EXE（连同自己放的 ffmpeg.exe，如有）移进去（是移，不是拷；移过去后删掉旧位置那个，不要再从旧位置打开），再从新位置打开、重新检查更新。设置和登录不受影响。

### 点菜单“退出”和点窗口右上角 X 一样吗

一样了。顶级菜单里的“退出”（Alt+X）、托盘右键菜单里的“退出”、点窗口右上角的 X、按 Alt+F4，四路关窗时都先问是最小化到托盘还是关闭，默认最小化。最小化后播放继续，托盘图标单击、双击、右键菜单或者 Shift+上翻页可以叫回窗口。

### 播放中突然没声音、位置也不动

先等一等。位置连续 15 秒不动会播报“播放停滞。”，网络缓过来就自己续上。如果一直不动，按 I 听一下最近一次错误，或者换个清晰度、重新点播。

### 搜不到、列表一直转圈

先看网络和代理。设置里代理留空是自动读系统代理；如果你的代理不是系统代理，把手动代理地址填进去，保存后重试。登录状态下的搜索走官方接口，有每日次数限制，用完会自动退回另一路继续搜，不登录也能搜。
